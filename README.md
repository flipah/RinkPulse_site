# RinkPulse Site

This folder is the source of truth for the public RinkPulse website.

Use this folder for site-only work:

- homepage updates
- hockey stats tools and search-focused landing pages
- user guide updates
- privacy policy updates
- support page updates
- GitHub Pages settings files such as `CNAME`
- website images and marketing assets under `assets/`

Do not put Garmin watch app source, Android app source, release artifacts,
keystores, or Play/Garmin upload packages in this folder.

Current domain:

```text
rinkpulsehockey.com
```

Expected GitHub Pages layout:

```text
index.html
stats-lab.html
stats-lab.js
guide.html
privacy-policy.html
support.html
styles.css
CNAME
assets/
```
